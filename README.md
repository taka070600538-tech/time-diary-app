# 時間管理ダイアリー

1日のタイムラインを記録し、睡眠・運動・勉強時間などを自動計算するPWAです。
Google AI Studioで作成した「時間管理ダイアリー」を参考に、時刻項目と自動計算区間を
自由に編集できる形で再実装しました。

## 公開URL

https://taka070600538-tech.github.io/time-diary-app/

## 機能

- **タイムライン入力**: 1日の時刻をタイムライン形式で入力。自動計算区間（睡眠時間・勉強時間など）を即時表示
- **分析・グラフ**: 区間ごとの平均・週合計・直近7日間の推移をグラフ表示
- **項目の編集**: 時刻項目・自動計算区間を自由に追加・変更・削除・並べ替え
- **CSVダウンロード**: 全記録をCSV形式で書き出し
- **GitHub自動バックアップ**: 共有基盤([app-sync](https://taka070600538-tech.github.io/app-sync/v1/sync.js))経由で、1日1回自動的に非公開の`app-data`リポジトリへバックアップ

## データの流れ

1. 入力内容はブラウザのlocalStorageに即時保存
2. アプリを開いたとき、1日1回`app-data/time-diary/backup.json`へ自動バックアップ（手動保存ボタンもあり）
3. PC側では毎日の自動pullタスクが`app-data`を取得し、前日以前の記録をObsidianのデイリーノート
   （`01_日記/YYYY-MM-DD.md`）へ自動転記
